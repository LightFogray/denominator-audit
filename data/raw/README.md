# Raw data

Raw inputs are not redistributed because of size and provider terms. The small
public `nyc_taxi_zones.zip` boundary is included so that the NYC audit can be
inspected without a separate download.

See `../../docs/data_provenance.md` for source URLs and the variables used.
The build scripts in `experiments/d1_denominator/` document the preprocessing
steps; they expect the original files under `data/raw/` and the project-specific
intermediate files under `data/processed/`.
